# Sync core fields and preserve local metadata

The MVP synchronizes title, description, status, due date, estimate, and priority bidirectionally. When a personal routing label creates a new external issue, the engine assigns the authenticated user in both workspaces. After creation, the user's assignee state is reflected one way from external to personal: external assignment assigns the personal issue to the user, and external unassignment clears that assignment; personal assignee changes do not update the external issue. Ordinary labels, team, project, cycle, parent, blocked or related links, and comments remain workspace-local and are never overwritten by the engine. This keeps cross-workspace field mappings explicit while preserving metadata that cannot be safely translated between workspaces.
