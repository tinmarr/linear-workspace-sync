# Sync core fields and preserve local metadata

The MVP synchronizes title, description, status, due date, estimate, and priority bidirectionally. When a personal routing label creates a new external issue, the engine assigns the authenticated user in both workspaces. After creation, the user's assignee state is reflected one way from external to personal: external assignment assigns the personal issue to the user, and external unassignment clears that assignment; personal assignee changes do not update the external issue. Ordinary labels, team, project, cycle, parent, comments, and the special personal mapping link remain workspace-local. Issue resources are synchronized separately by URL and title. Native issue relationships are governed separately by the relationship synchronization rules. This keeps cross-workspace field mappings explicit while preserving metadata that cannot be safely translated between workspaces.
